# Web agent rules

This installed Next.js version has breaking changes from earlier releases. Before changing Web code, read the relevant guide in `node_modules/next/dist/docs/`, resolved from this app directory, and follow its current APIs and deprecation notices.

Agent instructions are maintained manually. `agentRules: false` in `next.config.ts` disables automatic agent-file generation; keep this file and the root AGENTS rules rather than recreating tool-generated instruction shims.
