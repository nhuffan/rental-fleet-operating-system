# Rental Fleet API

Backend của Rental Fleet Operating System, được xây dựng bằng NestJS và TypeScript theo kiến trúc modular monolith. Đây là nơi triển khai API và logic nghiệp vụ quản lý cho thuê xe, vận hành đội xe và kiểm soát quyền truy cập theo doanh nghiệp.

Hiện tại backend ở giai đoạn nền tảng, chưa triển khai các module nghiệp vụ.
